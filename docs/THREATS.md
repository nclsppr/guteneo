# Threats, controls and limits

| Threat                       | Implemented boundary                                                                                                                       | Residual qualification                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| Tenant confusion / IDOR      | Auth0 subject -> DB membership; session-bound org; tenant composite FKs and tenant-scoped queries, dedupe and idempotency                  | Penetration test with real Auth0 delegation pending                                          |
| Model self-approval          | Browser approval by default; bounded owner/admin opt-in per OAuth connection via cookie + Origin/CSRF, exact short-lived review hash, revision and atomic budget fence                               | Initial browser delegation required; record delegated authority distinctly, respect host confirmation, never trust an LLM assertion as proof of fresh human consent                      |
| Double physical send         | Atomic quota/outbox; one conditional attempt; unknown outcome cannot replay                                                                | Supplier-specific reconciliation and operator runbook required                               |
| Webhook spoof / disorder     | Raw signature verification, durable receipt, duplicate keys, orphan reconciliation, channel-specific projection                            | Provider remote callback configuration untested                                              |
| Malicious PDF                | Bytes/EOF/parser validation, active object rejection locally; production scan before isolated parsing; quarantine when capabilities absent | No production scanner installed, scanner/parser isolation needs staging hostile-file testing |
| HTML/script/CSS exfiltration | Positive HTML list; user CSS/images/SVG removed; no script; all browser requests blocked; iframe sandbox email preview                     | Loss of unsupported styling is shown in final preview before approval                        |
| SSRF                         | URL imports disabled by default; exact trusted HTTPS hostname list, no credentials/ports/redirects, bounded bytes and time                 | Exact source service must be qualified; arbitrary DNS-controlled hosts never allowed         |
| Content/compute abuse        | Membership write check before side effect; per-org HTTP and documentary daily ceilings; new real orgs receive no credits; no live sends    | Turnstile and account-risk workflow deferred before public signup rollout                    |
| Storage exposure             | Private organization-scoped R2; authenticated previews; no content/URL/token logging                                                       | External log policy and operator access review pending                                       |
| Marketing abuse              | Marketing send preparation refused; org-local hard-bounce/complaint suppression                                                            | Unsubscribe/consent UI and real reputation policy needed to enable marketing                 |
| Recovery duplicate           | Consumers stopped for restore, expired attempts treated unknown, provider facts reconciliation before replay                               | Local restore rehearsal differs from remote account/R2 disaster recovery                     |

No platform-operator content access exists. Organization admins only see their own organization. Access requiring a break-glass operator role is deferred and must add per-case permission plus content-access audit, not a wildcard role.

Production simulation and local auth fail closed. Live tariffs/sends are deliberately blocked, even with a configured API key. This prevents accidentally spending based on illustrative test credits. Development antivirus bypass is labelled Simulation and cannot run as production.

The browser PDF preview bounds final canvas output and preflights referenced image XObject dimensions before decoding. A regression test covers explicit rejection above16MP. PDF.js's maxImageSize alone was insufficient: it could silently omit that image even with stopAtErrors. The added preflight does not prove complete resource safety for every inline image or adversarial compressed stream. Browser preview is not the production malware scanner or isolated validator; qualify those separately before accepting live customer content.

Expert delegation adds a deliberate residual risk: an assistant with the approved OAuth scopes can spend within its mandate. Prompt injection or a mistaken instruction cannot be reliably disproved by an LLM-provided Boolean. Therefore limits, channels, expiration, current-owner checks, revision-bound reviews and atomic daily accounting are enforced independently by the server. Changing or revoking a mandate invalidates pending reviews; quota consumption from already accepted commands survives cancellation and policy changes. Postal draft transfer has a separate recorded authority and count cap; it never authorizes dispatch implicitly. OAuth tokens and review tokens are not logged; only review hashes are stored. A host may still require its own tool confirmation.
