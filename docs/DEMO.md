# Demonstration

## Executable local demo

Run README setup and `npm run demo`. The Simulation banner stays visible. Use only fictitious content; the local antivirus bypass is explicitly displayed. Two organizations have separate membership, documents, senders and test ledgers.

Generate a letter from harmless HTML in Documents. Open its actual PDF preview; source says generated. Import an existing valid PDF separately and verify its SHA256 and source says original. Neither operation sends anything. Prepare an email to a reserved `example.invalid` address; include HTML/text and optionally the same PDF. Review the final sanitized content, sender/recipient/channel/ceiling, approve the fingerprint, then confirm. Queue simulation returns a labelled channel outcome and timeline with the same dispatch ID.

Prepare postal correspondence with clearly fictitious demonstration address. Simulation can show a simulated handover to post; it never means real printing, postage or delivery. For fax, the product accepts a user-supplied FR/LU/DE E.164 number in simulation. No real demonstration number, VBS fax number or contact is invented in the UI or integration configuration.

Create a named campaign, paste CSV with `channel,email,phone,name,line1,postalCode,city,country` columns. Duplicate and invalid rows are shown. Correct errors, choose shared PDF, prepare rows. Each operation is visible and requires review; current campaign membership freezes at first approval. Maximum500 rows; no automatic fallback channel.

Switch to the other fictional organization by logging out; original content/list/detail remains inaccessible. Administration can pause a channel before acceptance/submission. Automated tests exercise the unknown-result path without paid calls.

## MCP protocol proof locally

`node scripts/http-smoke.mjs --with-server` obtains a human local session, a short-lived explicitly local MCP token, calls the actual stateless HTTP handler and checks tools/fileParams and refusal to self-approve. This is protocol evidence, not ChatGPT/Claude/Cursor client certification.

Cursor adapter: CURSOR.md. Its stdio tool reads project-bounded PDF bytes, uploads automatically and checks the returned hash. A local path is never passed as though the remote Worker could read a disk.
