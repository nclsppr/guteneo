# Guteneo 1.3.0 — Remote MCP workflow skills

Guteneo 1.3.0 lets compatible assistants discover nine workflow skills over
MCP and verify their instructions and reference files. Corrected tool
annotations identify calls to external services and actions that can replace
settings or restrict access to a document. Since the last submission, users
can also save workspace recipients and prepare capped fax or message-only
email schedules. Approving future spending requires a separate browser review.

## Skills in connected assistants

The MCP server exposes nine workflow skills through the official Skills
extension for MCP 2026-07-28. A compatible host can inspect each manifest and
verify the Markdown and references it reads. Guteneo derives the catalog from
the workflow sources used by its downloadable plugins.

## Tool effects and review evidence

Review annotations now identify calls to independently controlled services,
including requests made to fixed provider endpoints. The published tool
descriptions and reviewer evidence document the operations behind those hints.

The authenticated connection serves the catalog. Reading instructions grants
no authority to execute a tool. Existing hosts can continue to use the
packaged workflows, MCP prompts and tools. The SDK client tests exercise local
discovery and file verification. Hosted compatibility and marketplace decisions
require their own evidence.
