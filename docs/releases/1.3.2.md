# Guteneo 1.3.2 — Look up a purchased PDF validation report

Guteneo 1.3.2 renames the MCP tool for retrieving a purchased PDF/UA or PDF/A
report to get_pdf_validation_by_key. It returns the report for the original
PDF, selected profile and request key. An administrator can purchase a new check
in the Guteneo browser.

## Finding a report in a connected assistant

The PDF accessibility skill uses `get_pdf_validation_by_key` when the original
request key is available. With just the document ID, `get_pdf_validation`
lists up to 50 reports for that document. Both lookups enforce document access.
The exact-key lookup retains the `documents:write` scope used by existing
connections. The report list requires `documents:read`.

Clients with a cached `validate_pdf` call can still retrieve the same report
with the same arguments and permissions. Refresh the tool list to discover
`get_pdf_validation_by_key` and use it for new calls.
