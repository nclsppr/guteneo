# Guteneo 1.2.3 — Clearer documents, decisions and workspaces

This update completes the recovered frontend clarity plan on the current main
foundation. Documents, preparation, review, reporting and personal reading use
clearer layouts while retaining exact prices, authority and recovery choices.

## What changes

- Shared statistics, readable empty states, compact recoverable tables and useful
  disclosures reduce repeated instructions across the applications.
- Dispatch review keeps the priced decision visible, provides a copiable
  reference and follows uncertain outcomes without proposing an automatic retry.
- Preparation offers clearer channel choices and indicative catalog prices,
  translated validation, searchable countries and file drop zones.
- Studio renders bounded local template thumbnails on demand. Its libraries
  refresh on return without losing unsent input. Public preview adds read-only
  Studio examples with explicit write refusal and no business API fallback.
- Personal documents gain committed search, direct document links, expiry cues
  and a more usable reader/history layout. Administration separates Operations
  from reports and simplifies exports, activity and billing. Belvédère shares
  statistic components and clearer financial cells.
- Application timestamps, date filters, report periods and schedule/mandate
  inputs consistently use UTC. Each frame declares that clock once; provider
  processing cutoffs keep their published business timezone.
- Unsaved application navigation uses a translated confirmation with Cancel
  focused first. Its single-use continuation remains bound to the same route,
  authority and navigation state, including workspace changes and Back/Forward.
- Browser approval requests record an idempotent request against the exact
  prepared version. Private PDF check history exposes bounded metadata under
  current document visibility. Neither operation grants sending approval.

## Validation and release scope

The attached portable CI report identifies the tested source, workflow attempts,
assertions, browser inventory and declared exclusions. Earlier local results and
macOS browser startup failures are kept separately in the execution record;
they do not substitute for successful hosted tests.

Migrations 0081 and 0082 add lookup indexes only. Manual production publication
requires exact current main, its immutable version tag, complete successful CI,
live schema/ledger and integrity verification, followed by the existing served
asset verifier. Missing D1 or application credentials stop publication.

Saved recipients, signed customer webhooks, capped future schedules and durable
iOS drafts from main remain intact. This release does not activate disabled
tenant/provider gates, enable expert delegation, send real communications or
establish a native distribution result.
