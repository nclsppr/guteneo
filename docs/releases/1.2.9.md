# Guteneo 1.2.9 — Luxembourg fax pilot extension

The existing Luxembourg fixed-line `+3524` pilot can resume after an operator
activates its scoped extension. The pilot ends at midnight in Paris at the
start of 1 June 2027. The maximum remains ten pages and a EUR2 ceiling per
fax. Each dispatch retains its approval requirements.

The existing scheduler reads current Telnyx tariff and sender evidence and the
current ECB conversion before issuing a tariff valid for at most seven days.
Local Calling remains unverified for the pilot. The migration preserves the
original tariff and quote records. See the
[pilot maintenance contract](../FAX_TARIFF_MAINTENANCE.md#june-2027-pilot-extension)
for activation, verification and release order.

Isolated tests exercise the populated migration, authorization boundary and
freshness reconciliation. Production availability requires a successful
scheduled refresh after activation.
