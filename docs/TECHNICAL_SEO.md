# Public HTML and crawl boundaries

The public site builds complete HTML documents for every route in `packages/contracts/src/public-site.json`. Their source is the same React content supplied by `apps/web/src/editorial/ssr.tsx`; the build uses Vite `ssrLoadModule` and injects the rendered markup into the built document. CSS and the application entry come from the ordinary hashed production build. Every public page retains the entry to apply the visitor's language or saved account preference and operate its language selector. Journal and legal content remains readable without JavaScript.

Each page has its own title, description, absolute canonical URL, Open Graph/Twitter metadata and the structured data supplied by the editorial module. Structured JSON escapes HTML delimiters before insertion. Article and breadcrumb facts must match visible content; the builder does not invent dates, authors, ratings or FAQ claims. Missing content or a mismatched canonical fails the build.

The primary `guteneo.com` preview allows indexing of these public pages and publishes a sitemap containing the generic routes and their four explicit language variants. Private API/auth/media routes remain blocked. The fragment workspace has no separate URL in the sitemap; fragments are not used as editorial routes. The `workers.dev` preview returns `X-Robots-Tag: noindex, nofollow` and a disallow-all robots response. The production build now also emits indexable public HTML for the eventual canonical-domain cutover. Its static `_headers` remain noindex by default. The production Worker runs before every asset, checks the exact canonical HTTPS origin, public path or image response, response status and sensitive query keys, then removes noindex only for permitted GET/HEAD 200/304 responses. The header stays noindex on `workers.dev`, unknown hosts, private query parameters, machine JSON, 404s and failures. API/auth/write requests retain the existing Hono middleware and its noindex/authentication gates.

Workers Static Assets uses real missing-file 404s, without the former SPA fallback. Folder index documents use trailing slash canonical routes. Release verification maps every nested `/index.html` asset to its canonical folder route, verifies its exact bytes, and never follows arbitrary redirects. The public-page generator runs before the source snapshot recheck and asset-manifest hash; both build scripts include it and the release verifier in their snapshot scope. A source change during rendering aborts the release candidate.

Tests cover generated raw HTML, safe metadata, no-JavaScript pages, incomplete-build rejection, the primary/fallback header distinction, preserved backend 403s, 404s and canonical redirects. Browser checks inspect HTTP source and navigate the journal with JavaScript disabled. Build/test/deployment results are recorded separately when run; crawl eligibility does not establish actual Google indexing or ranking.

The host-aware cutover candidate is local only: `wrangler.live.jsonc` still has no domain routes, and this change does not move `guteneo.com`. `apps/api/src/worker.ts` wraps only fetch; queue, scheduled handlers and the private ProviderInspection entrypoint remain intact. `public-assets.ts` serves static bytes independently of Auth0 after the base environment/mode/HTTPS checks; missing identity continues to close account/API routes. The public route list and private prefixes are shared by the build, preview and production in `packages/contracts/src/public-site.json`.

Canonical `/index.html` and missing-slash redirects keep their real HTTP status and destination, with `noindex, follow`; fallback redirects remain `noindex, nofollow`. The middleware does not rewrite HTML, alter asset hashes/ETags or cache responses across hosts. Indexable HTML metadata therefore remains identical on both hosts, while the more restrictive fallback HTTP noindex header is authoritative. Runtime `/robots.txt` is allow-public/disallow-private plus the canonical sitemap only on `https://guteneo.com`; other origins and private query variants return disallow-all. Robots, sensitive queries, release metadata and sitemap use no-store. An accidental asset-first path still inherits the static default noindex.

Local qualification: 28 asset-policy unit tests plus 6 configuration and 37 preview-boundary tests pass. The actual production entry is bundled only into a temporary directory and exercised with real Miniflare Static Assets: all six paths, both hosts, unchanged bytes, `_headers` precedence, HEAD/304, canonical redirects, missing assets, image policy, robots/sitemap, cache separation and closed identity routes are covered. No shared dist build or deployment is needed for that test. Domain routing, deployment proof, Google Search Console verification and actual indexing remain separate.

The two article illustrations were generated specifically for Guteneo using the image-generation tool. Originals and exact prompts are retained under `assets/editorial/source/`, with dimensions and SHA-256 hashes. Responsive WebP derivatives are served at 1536×1024 and 720×480. Visible captions identify them as contemporary illustrations rather than documentary reconstructions. Historical sources remain separate, with references beside each chapter and full links at the end.

## Multilingual link previews — 3 October 2026 candidate

The generic public URLs have a language-neutral Open Graph/Twitter preview: `guteneo`, `guteneo.com`, and an ivory/cobalt card containing the approved blue portrait, three website swallows and one lowercase `guteneo.com` signature in the website’s black ink. This applies to all 18 public routes. Their ordinary SEO title, description and initial page content remain French; browser preferences may change the visible interface after loading.

An explicit `?lang=fr`, `?lang=en`, `?lang=de` or `?lang=lb` selects a complete pre-rendered document: localized page content, HTML language, title/description, Open Graph/Twitter text, image description, canonical URL and structured data. Every page declares the four language alternatives plus `x-default`, and the sitemap contains 90 public URLs. The journal and its two articles retain their editorial illustrations in explicit-language previews. Other localized routes use the matching brand card. No language is inferred from a crawler's IP, cookies or `Accept-Language`.

`packages/contracts/src/public-locales.ts` accepts one bounded, supported language tag; regional forms such as `de-AT` normalize to `de`. Missing, unsupported or duplicate `lang` parameters select the neutral preview. The production and preview Workers select an immutable file under `/__public-locales/{language}/` only for an existing public route. They apply header/private-query policy using the original public URL, preserve HEAD/ETag/304, and return 404 if a variant is missing. Direct requests to the internal namespace return 404. The release verifier maps every internal manifest entry back to its public `?lang=` URL and still verifies every byte and hash on both origins. The response HTML is never rewritten at request time.

Public language selections add the language to the address bar. Existing public fragments and harmless query parameters survive. Explicit language is retained in ordinary internal links, including after React replaces the initial HTML, so copying a link or navigating with browser storage disabled still preserves the selection. Account preferences and private application routes retain their existing behavior. Client social metadata and structured data follow the explicit URL after selection; the server HTML fetched from that same URL is the authoritative share preview.

The five committed PNGs are 1200×630. `packages/contracts/src/social-cards.json` records their paths, dimensions, MIME types and descriptions. The editable composition is `docs/brand/social-card.html`; regenerate with `node scripts/build-social-card.mjs` after `npm ci` and installing Playwright Chromium if needed (`npx playwright install chromium`). The renderer embeds the approved portrait and packaged EB Garamond/IBM Plex Sans fonts without network requests, checks text bounds and the black ink against the website’s `--ink` token, rejects duplicated brand lettering, and ensures the neutral card contains only the single lowercase `guteneo.com` signature. All source brand assets remain unchanged. Use a new image filename for future artwork revisions.

The image/locale metadata follows the [Open Graph protocol](https://ogp.me/). The image filename changes prevent reuse of older image bytes, but sharing platforms may retain a cached page preview until they fetch the URL again. Local browser simulations do not establish rendering in Discord, WhatsApp or another external application. This is an implementation candidate; no production deployment or real message has been performed.
