# Public HTML and crawl boundaries

The public site builds complete HTML documents for every route in `packages/contracts/src/public-site.json`. Their source is the same React content supplied by `apps/web/src/editorial/ssr.tsx`; the build uses Vite `ssrLoadModule` and injects the rendered markup into the built document. CSS and the application entry come from the ordinary hashed production build. Every public page retains the entry to apply the visitor's language or saved account preference and operate its language selector. Journal and legal content remains readable without JavaScript.

Each page has its own title, description, absolute canonical URL, Open Graph/Twitter metadata and the structured data supplied by the editorial module. Structured JSON escapes HTML delimiters before insertion. Article and breadcrumb facts must match visible content; the builder does not invent dates, authors, ratings or FAQ claims. Missing content or a mismatched canonical fails the build.

The primary `guteneo.com` preview allows indexing of these public pages and publishes a sitemap containing only those six canonical HTTPS URLs. Private API/auth/media routes remain blocked. The fragment workspace has no separate URL in the sitemap; fragments are not used as editorial routes. The `workers.dev` preview returns `X-Robots-Tag: noindex, nofollow` and a disallow-all robots response. The production build now also emits indexable public HTML for the eventual canonical-domain cutover. Its static `_headers` remain noindex by default. The production Worker runs before every asset, checks the exact canonical HTTPS origin, public path or image response, response status and sensitive query keys, then removes noindex only for permitted GET/HEAD 200/304 responses. The header stays noindex on `workers.dev`, unknown hosts, private query parameters, machine JSON, 404s and failures. API/auth/write requests retain the existing Hono middleware and its noindex/authentication gates.

Workers Static Assets uses real missing-file 404s, without the former SPA fallback. Folder index documents use trailing slash canonical routes. Release verification maps every nested `/index.html` asset to its canonical folder route, verifies its exact bytes, and never follows arbitrary redirects. The public-page generator runs before the source snapshot recheck and asset-manifest hash; both build scripts include it and the release verifier in their snapshot scope. A source change during rendering aborts the release candidate.

Tests cover generated raw HTML, safe metadata, no-JavaScript pages, incomplete-build rejection, the primary/fallback header distinction, preserved backend 403s, 404s and canonical redirects. Browser checks inspect HTTP source and navigate the journal with JavaScript disabled. Build/test/deployment results are recorded separately when run; crawl eligibility does not establish actual Google indexing or ranking.

The host-aware cutover candidate is local only: `wrangler.live.jsonc` still has no domain routes, and this change does not move `guteneo.com`. `apps/api/src/worker.ts` wraps only fetch; queue, scheduled handlers and the private ProviderInspection entrypoint remain intact. `public-assets.ts` serves static bytes independently of Auth0 after the base environment/mode/HTTPS checks; missing identity continues to close account/API routes. The public route list and private prefixes are shared by the build, preview and production in `packages/contracts/src/public-site.json`.

Canonical `/index.html` and missing-slash redirects keep their real HTTP status and destination, with `noindex, follow`; fallback redirects remain `noindex, nofollow`. The middleware does not rewrite HTML, alter asset hashes/ETags or cache responses across hosts. Indexable HTML metadata therefore remains identical on both hosts, while the more restrictive fallback HTTP noindex header is authoritative. Runtime `/robots.txt` is allow-public/disallow-private plus the canonical sitemap only on `https://guteneo.com`; other origins and private query variants return disallow-all. Robots, sensitive queries, release metadata and sitemap use no-store. An accidental asset-first path still inherits the static default noindex.

Local qualification: 28 asset-policy unit tests plus 6 configuration and 37 preview-boundary tests pass. The actual production entry is bundled only into a temporary directory and exercised with real Miniflare Static Assets: all six paths, both hosts, unchanged bytes, `_headers` precedence, HEAD/304, canonical redirects, missing assets, image policy, robots/sitemap, cache separation and closed identity routes are covered. No shared dist build or deployment is needed for that test. Domain routing, deployment proof, Google Search Console verification and actual indexing remain separate.

The two article illustrations were generated specifically for Guteneo using the image-generation tool. Originals and exact prompts are retained under `assets/editorial/source/`, with dimensions and SHA-256 hashes. Responsive WebP derivatives are served at 1536×1024 and 720×480. Visible captions identify them as contemporary illustrations rather than documentary reconstructions. Historical sources remain separate, with references beside each chapter and full links at the end.
