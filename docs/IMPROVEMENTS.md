# Product and engineering review

| Improvement                              | Problem / benefit                                                                           | Cost / risk                                                                 | Decision                                                                                                            |
| ---------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Immutable preflight and review sheet     | User sees transformed HTML/text, exact PDF hash, sender, recipient and cost before approval | Low UI cost; extra fields must remain fingerprint bound                     | Implemented in shared preparation + preview                                                                         |
| Actionable uncertainty and channel stop  | A generic error could encourage duplicate physical sends                                    | Low; never exposes a blind retry                                            | Implemented unknown state/timeline/admin pause control                                                              |
| Document budgets and resumable retention | Sending limits alone do not cap upload/render spending or storage                           | Medium SQL and maintenance work; must preserve active documents             | Implemented with concurrent-budget and >25-row retention regression tests                                           |
| Assistant connection diagnostic card     | OAuth and file capability uncertainty wastes onboarding time                                | Low UI; avoid claiming actual client compatibility                          | Implemented capabilities/matrix/connection controls; real-client check pending                                      |
| Native MCP Apps preview                  | Could shorten human review inside a compatible assistant                                    | Medium; client-specific trust, consent and file presentation must be proven | Deferred until real OAuth/file transfers are qualified; complete text result and authenticated review link retained |

These changes preserve confirmation, do not substitute channels and do not label simulated results as real deliveries. No CRM, internal LLM, newsletter editor or billing checkout was added.
