Test strategy without business charges
  1. Run application code locally with synthetic data, isolated D1 databases and R2 objects, queues and the required PDF components.
  2. Block external networking and exclude production secrets. The final delivery call uses only a simulated provider; any unexpected network access fails the test.
  3. Retain evidence for each scenario: environment, result, date, duration and limitation. A scenario that has not run receives no passing status.
  4. Keep production outside this loop. Public collection is bounded and uses infrastructure; its cost cannot be described as zero. Do not include a billable business workflow in this loop.

Goal: no real quote consumed, no business credit reserved and no provider payment. Machine and any CI resources remain separate. Local qualification publishes a dated result under Verification. Uncovered scenarios still need completion.
