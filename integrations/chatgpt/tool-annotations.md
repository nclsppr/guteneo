# Justification des annotations MCP — candidat du 4 octobre 2026

Cette table couvre les **66 outils** enregistrés quand les services postaux, le
studio et le diagnostic PDF sont raccordés dans [mcp.ts](../../apps/api/src/mcp.ts).
Elle décrit le candidat local, pas une publication ou une recette ChatGPT.
Comparer le prochain **Scan Tools** au serveur effectivement déployé avant
soumission. Les anciens 24 outils ne constituent plus le catalogue complet.

## Effets et confirmations de l’hôte

Les 66 outils déclarent `readOnlyHint: false` et `idempotentHint: false` : après une
réponse réussie et validée, le wrapper commun enregistre la dernière utilisation
de la connexion. Les clés métier conservent leur rôle de non-duplication ; cette
observation supplémentaire ne déclenche aucun renvoi ni nouveau diagnostic.
`validate_pdf` conserve notamment la même réponse métier pour une même clé et les
mêmes octets/profil, même si l’activité de connexion avance.

Quatre outils de studio annoncent maintenant `destructiveHint: true` :
`update_template` écrase le brouillon courant sans historique de chaque édition ;
`archive_template` interdit les nouvelles éditions/publications/générations sur
ce modèle ; `share_template` remplace les permissions et peut révoquer un accès ;
`cancel_generation_job` annule les travaux en attente sans reprise de ce même lot.
Les versions publiées et les PDF déjà produits restent conservés. Le contrôle
`expectedRevision` protège les mutations de modèles contre une édition concurrente.
La duplication d’un modèle archivé crée un autre modèle ; elle ne restaure pas
l’objet archivé. Le correctif ne change aucun handler, droit, scope, mandat,
confirmation d’envoi, débit ou appel fournisseur.

Les [règles OpenAI de classification](https://developers.openai.com/plugins/plugin-guidelines#correct-annotation)
consultées le 4 octobre demandent le marqueur destructif pour l’écrasement,
l’annulation ou la révocation d’accès, même si une action ultérieure peut rétablir
un état similaire. Les [annotations de référence](https://developers.openai.com/plugins/reference#annotations)
informent les confirmations de l’hôte ; elles ne remplacent jamais les contrôles
serveur ni un consentement humain. Aucun widget HTML ni ressource MCP Apps n’est
enregistré : les PDF/images et liens de consultation ne sont pas un widget.
